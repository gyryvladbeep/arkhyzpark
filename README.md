# Архызпарк

Сайт горной инструкторской службы «Архызпарк» (Архыз, Кавказ).

## Статус

Черновой макет (single-page демо) для внутреннего показа заказчику.
Контент, фото и карточки инструкторов на странице — примеры, помечены как черновые.

## Стек (текущий этап)

Статическая страница: HTML + CSS + JS, без сборки. Задеплоена на Vercel как статический сайт.

Планируется миграция на Next.js + Supabase при добавлении реального бэкенда
(форма бронирования, админка, отзывы) — см. переписку с Claude по архитектуре проекта.

## Разработка

Открой `index.html` в браузере — сборка не требуется.
